# Practical evidence guide

Collect these items by running the practicals yourself. Keep original files and record the date, software version and test performed.

## Task 1 – Office redesign
- Run `python office_bandwidth.py`.
- Build the extended-star topology in Packet Tracer and test PC-to-server connectivity.
- Save the actual `.pkt` project and screenshots.

## Task 2 – Hospital topology
- Run `python topology_comparison.py`.
- Build the proposed five-block hybrid topology.
- Test Emergency and Operating Theatre connectivity, then disable each critical core link separately and record the ping results.

## Task 3 – Cabling
- Run `python cabling_check.py`.
- Add actual cable-route measurements, termination photographs and the final bill of materials if required by the assignment.

## Task 4 – Shared media and WLAN
- Run `python shared_media.py`.
- Record the real AP/site-survey results if a wireless practical is required. The AP count in the report is a planning estimate, not a measured result.

## Task 5 – VLANs
- Apply `access_switch.cfg` and `router_on_a_stick.cfg` to the topology after checking interface names.
- Verify VLAN membership, trunk status, allowed inter-VLAN traffic and guest ACL restrictions.
- Save actual command output and Packet Tracer screenshots.

## Task 6 – Campus design
- Run `python campus_design_check.py`.
- Build the reduced campus topology, test permitted and blocked traffic, then test a core-link failure and ISP failover if configured.
- Save the actual Packet Tracer project and screenshots.

Do not mark a test complete until it has been run. Do not upload credentials or private network details.
