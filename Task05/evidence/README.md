# Task 5 validation
1. Assign one PC to each VLAN and configure the gateway addresses.
2. Verify VLAN membership with `show vlan brief`.
3. Verify Gi0/1 trunk and allowed VLANs with `show interfaces trunk`.
4. Before inter-VLAN routing, confirm PCs in different VLANs cannot ping.
5. After router-on-a-stick, verify Office↔CCTV only if policy allows.
6. Confirm Guest cannot reach Office/CCTV/private address ranges but can reach an allowed internet test destination.
7. Save Packet Tracer .pkt and screenshots here. Actual ping output is required; do not mark the tests complete until run.
